# mobile-electronics-and-appliances-shop
# 📱 Shri Ganesh Enterprises

A modern and responsive electronics e-commerce website built using **HTML5, Tailwind CSS, and JavaScript**. The project includes product management, shopping cart, wishlist, admin dashboard, dark mode, WhatsApp ordering, and responsive UI features.

---

## 🚀 Technologies Used

* HTML5
* CSS3
* Tailwind CSS
* JavaScript (ES6)
* Font Awesome
* Google Fonts
* LocalStorage API
* SessionStorage API
* WhatsApp API
* Google Maps Embed API

---

## ✨ Features

* Responsive Design
* Dark Mode Support
* Product CRUD Management
* Shopping Cart System
* Wishlist Functionality
* Product Search & Filters
* WhatsApp Checkout
* Admin Login Panel
* JSON Backup & Restore
* Smooth Animations & Modern UI
